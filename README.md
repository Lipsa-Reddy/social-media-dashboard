# 📱 Social Media Engagement Dashboard

An interactive web-based data dashboard built to track and analyze content engagement metrics across platforms like Instagram and YouTube. Built specifically using Python and Streamlit, optimized for lightweight, cloud-based data tracking.

## 🚀 Features
- **KPI Metrics:** Automatically tracks Total Impressions, Total Engagement, and Engagement Rates.
- **Advanced Filtering:** Dropdown sorting for social platforms and granular calendar date range sliders.
- **Interactive Graphs:** Dynamic line charts tracking impressions over time and bar graphs displaying cross-platform metrics.
- **File Upload Support:** Upload any custom social media metric CSV directly to update the dashboard values instantly.

## 🛠️ Tech Stack
- **Language:** Python
- **Framework:** Streamlit
- **Libraries:** Pandas, Plotly, NumPy
- **Environment:** GitHub Codespaces (Linux Cloud Dev)
